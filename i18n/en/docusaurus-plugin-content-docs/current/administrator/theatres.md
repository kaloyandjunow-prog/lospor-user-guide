# Operating theatres

**Clinical setup → Operating theatres** decides whether cases are given an
operating theatre.

![Operating theatres](/img/screens/en/status-control_theatres.png)

## Switching it on

It is off by default, and LOSPOR comes with no theatre names. Tick **Assign
operating theatres to cases**, give a reason and your password, and **Save
the switch**. Clinicians then see the theatre on the dashboard, in each case
and on the printed record, and the unit indicators show figures by theatre.

## The list

- **New theatre** then **Add**: one name, shown as written in both languages,
  up to 60 characters. Two active theatres cannot share a name.
- **↑ ↓** set the order the clinicians' menus show.
- **Rename** changes the name on cases that have not started yet. The button
  shows how many cases carry the theatre.
- **Retire** takes a theatre out of the menus. Cases that had it keep it.
  **Retired theatres**, below the list, can be restored.

## How clinicians use it

On the web, **Theatre** in the case's row on the dashboard; on the phone,
hold the case. It can be changed until anaesthesia starts. See
[The dashboard](../clinician/dashboard.md).
