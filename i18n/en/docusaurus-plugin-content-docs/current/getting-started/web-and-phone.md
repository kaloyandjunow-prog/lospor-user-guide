# Web and phone

LOSPOR has two faces over the same records.

| | On a computer (web) | On a phone or tablet (app) |
|---|---|---|
| Best for | The preoperative visit at a desk, reviewing and printing, the unit's figures | The operating theatre and recovery |
| Opens at | the LOSPOR address in a browser | the same address, added to the home screen |
| Case forms | one page per step, with a side panel | one section at a time, swiped |
| Without a connection | saves wait in the browser | the whole case keeps working |

![The dashboard on the web](/img/screens/en/web-dashboard.png)

## Putting LOSPOR on the phone

Open the LOSPOR address in the phone's browser and sign in, then use the
browser's **Add to Home Screen** (Safari: Share → Add to Home Screen; Chrome:
⋮ → Install app). LOSPOR then opens full screen, like any other app.

![The dashboard on the phone](/img/screens/en/phone-dashboard.png)

## One record, two screens

Everything you enter is saved as you go — there is no Save button. A case
started on the phone can be continued on the computer a moment later, and the
other way round. An open case refreshes by itself when someone changes it
elsewhere.

### When a case is open in two places

Only one screen edits a case's chart at a time. If it is open somewhere else,
the other screen shows a banner ("…is currently editing this case") and your
changes there are not saved. Press **Take over editing** to continue on this
screen; the first screen then becomes the one watching.

## Without a connection

- **Phone:** keep working. Every entry is kept on the phone and sent when the
  connection returns. The header shows whether entries are saved or still
  waiting.
- **Web:** a counter in the top bar ("2 saves waiting") shows saves made
  without a connection; they are sent automatically once you are back online.
  Do not sign out while it shows a number — signing out discards them from
  this browser.

:::tip If something is refused
When the server refuses a value (a weight of 800 kg, or text that looks like a
patient's name), LOSPOR says so beside the field rather than showing it as
waiting. Correct it, and it saves.
:::
