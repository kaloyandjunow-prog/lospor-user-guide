# Glossary

**Case** — one anaesthetic, from the preoperative assessment to the printed
record.

**Case code** — the case's number, for example `2026-0438`: the year and the
clinician's own sequence. It ties the printed record to LOSPOR. It may change
when a case is handed over.

**Status (of a case)** — where the case is: Draft, In consultation, Awaiting
allocation, In theatre, Awaiting postop review, Awaiting review, Case
finished, or Procedure cancelled. See [The case from start to finish](../clinician/workflow.md).

**Finished (finalised)** — closed and final: the record can no longer be
changed. Unfinalize is possible for 30 minutes after.

**Cancelled procedure** — an operation that did not happen, recorded with its
reason. See [Cancelled procedures](../clinician/cancelled-procedures.md).

**Handover** — passing a case to a colleague, who must accept. **Assign** —
the same, at once, by a head of department.

**Timetable / chart** — the intraoperative record in 5-minute columns (rows on
the phone).

**Bar** — something that runs over time on the chart: an infusion, a fluid,
an agent, the gas settings.

**Planned** — a change or stop dated after now; it takes effect when its time
comes.

**Ruleset** — the defaults behind the intraoperative menus (doses,
concentrations, equipment); personal, institution or platform.

**Unit indicators** — the department's aggregate figures. Not research.

**Cloud** — LOSPOR at app.lospor.org, run by the LOSPOR team.

**Hospital installation (LOSPOR Hospital, appliance)** — LOSPOR on a server
inside one hospital, run by its IT.

**Hospital patient number** — the number the hospital uses to link a case to
its patient. In the appliance it may be stored encrypted according to Status
permissions; only a pseudonym is sent when Central needs one.

**LOSPOR Central** — the central service to which the hospital installation
can automatically send eligible finished cases.

**Status (the console)** — the hospital installation's admin console.

**Go-live (Пускане в работа)** — the steps between "installed" and "approved
for clinical use".

**Research browser** — the separate website for researchers.

**Grant** — permission for one account to see or export research data, for a
purpose and a period.

**Pseudonym** — the code a case carries in research instead of anything that
identifies it.

**OMOP** — a standard format for observational health data (OMOP Common Data
Model 5.4), used for research exports.

**ICD-10 (МКБ-10)** — the diagnosis classification. **ICD-10-PCS** — the
procedure classification behind the exact operation.

**ЕГН** — the Bulgarian personal identification number. Never stored in the
cloud.

**Mistral** — the EU AI provider LOSPOR uses for lab and monitor scans and the
advisor. Used only when allowed for the hospital and ticked for the case.

**PWA** — the phone app, installed from the browser (Add to Home Screen).
